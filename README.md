В рамках работы создан игровой 2D-прототип в Unity, содержащий:
1. Персонажа игрока (`Player`).
2. **Обычного противника (`NormalEnemyAI`)** - использует конус зрения в 180° и патрулирование по точкам. 
3. **Телепортирующегося противника (`TeleportEnemyAI`)** - использует круговое сканирование на 360°, повышенный урон и механику телепортации.

Логика управления И�� построена на паттерне **Finite State Machine (FSM)**. Состояние каждого NPC обновляется в кадре (`Update()`), а переходы задаются набором условий, относящихся к позиции игрока, таймерам и состоянию окружения.
  

## Таблицы переходов состояний (FSM)

### Схема переходов: Обычный противник (`NormalEnemyAI`)

| **Текущее состояние** | **Условие перехода**                           | **Следующее состояние** |
| --------------------- | ---------------------------------------------- | ----------------------- |
| **Idle**              | Игрок обнаружен (`SeePlayer() == true`)        | **Chase**               |
| **Idle**              | Завершилось время ожидания (`stateTimer <= 0`) | **Patrol**              |
| **Patrol**            | Игрок обнаружен (`SeePlayer() == true`)        | **Chase**               |
| **Patrol**            | Достигнута точка патрулирования                | **Idle**                |
| **Chase**             | Дистанция до игрока $\le$ `attackRange`        | **Attack**              |
| **Chase**             | Игрок потерян из виду (`SeePlayer() == false`) | **Search**              |
| **Attack**            | Дистанция до игрока > `attackRange`            | **Chase**               |
| **Attack**            | Персонаж игрока уничтожен / отсутствует        | **Patrol**              |
| **Search**            | Игрок вновь обнаружен (`SeePlayer() == true`)  | **Chase**               |
| **Search**            | Время поиска истекло (`stateTimer <= 0`)       | **Patrol**              |

### Обычный противник (`NormalEnemyAI`)

- **Восприятие:** Направленное зрение под углом 180° с дальностью `viewDistance`. Для проверки препятствий используется raycast.
- **Патрулирование:** Перемещение между зафиксированными точками `patrolPoints`. По прибытии в точку NPC делает паузу и выбирает следующую цель.
- **Поиск:** При утере контакта NPC перемещается к `lastKnownPos` и начинает вращаться вокруг своей оси, имитируя осмотр ближайшей зоны.
### Телепортирующийся противник (`TeleportEnemyAI`)

- **Восприятие:** Круговое сканирование на 360° с радиусом `scanRadius` и заданным интервалом проверки `scanInterval`.
- **Способность телепортации:** При преследовании цели на расстоянии более 2.5 м противник выполняет телепортацию в сторону игрока, сохраняя скорость и агрессию.
- **Защита от застревания в стенах:** Перемещение производится с предварительной геометрической проверкой прохода и корректировкой маршрута.
