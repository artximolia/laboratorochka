## **Цель работы**

### Постановка задачи и архитектура системы

В рамках работы создан игровой 2D-прототип в Unity, содержащий:

1. Персонажа игрока (`Player`).
2. **Обычного противника (`NormalEnemyAI`)** — использует конус зрения в 180° и патрулирование по точкам.
3. **Телепортирующегося противника (`TeleportEnemyAI`)** — использует круговое сканирование на 360°, повышенный урон и способность к телепортации.

Логика управления построена на паттерне конечного автомата состояний (FSM). Состояние каждого NPC обновляется в каждом кадре, а переходы происходят в зависимости от условий восприятия, расстояния до игрока и текущего состояния.

## Таблицы переходов состояний (FSM)

### Схема переходов: Обычный противник (`NormalEnemyAI`)

| **Текущее состояние** | **Условие перехода** | **Следующее состояние** |
| --------------------- | -------------------- | ----------------------- |
| **Idle** | Игрок обнаружен (`SeePlayer() == true`) | **Chase** |
| **Idle** | Завершилось время ожидания (`stateTimer <= 0`) | **Patrol** |
| **Patrol** | Игрок обнаружен (`SeePlayer() == true`) | **Chase** |
| **Patrol** | Достигнута точка патрулирования | **Idle** |
| **Chase** | Дистанция до игрока ≤ `attackRange` | **Attack** |
| **Chase** | Игрок потерян из виду (`SeePlayer() == false`) | **Search** |
| **Attack** | Дистанция до игрока > `attackRange` | **Chase** |
| **Attack** | Персонаж игрока уничтожен / отсутствует | **Patrol** |
| **Search** | Игрок вновь обнаружен (`SeePlayer() == true`) | **Chase** |
| **Search** | Время поиска истекло (`stateTimer <= 0`) | **Patrol** |

### Обычный противник (`NormalEnemyAI`)

- **Восприятие:** направленное зрение под углом 180° с дальностью `viewDistance`. Для проверки препятствий используются `Physics2D.Raycast`, `obstacleLayer` и `playerLayer`.
- **Патрулирование:** перемещение между зафиксированными точками `patrolPoints`. По прибытии в точку NPC делает паузу в состоянии `Idle`.
- **Поиск:** при утере контакта NPC перемещается к `lastKnownPos` и начинает вращаться вокруг своей оси, имитируя осмотр местности.

### Телепортирующийся противник (`TeleportEnemyAI`)

- **Восприятие:** круговое сканирование на 360° с радиусом `scanRadius` и заданным интервалом проверки `scanInterval`.
- **Способность телепортации:** при преследовании цели на расстоянии более 2.5 м противник выполняет телепортацию к позиции рядом с игроком.
- **Защита от застревания в стенах:** перемещение производится с предварительной геометрической проверкой через `Raycast`.
