  ## **1. Цель работы**
  Постановка задачи и архитектура системы
В рамках работы создан игровой 2D-прототип в Unity, содержащий:
1. Персонажа игрока (`Player`).
2. **Обычного противника (`NormalEnemyAI`)** - использует конус зрения в 180° и патрулирование по точкам. 
3. **Телепортирующегося противника (`TeleportEnemyAI`)** - использует круговое сканирование на 360°, повышенный урон и механику пространственного перемещения.

Логика управления ИИ построена на паттерне **Finite State Machine (FSM)**. Состояние каждого NPC обновляется в кадре (`Update()`), а переходы происходят детерминированно при выполнении логических условий.
  

## Таблицы переходов состояний (FSM)

### Схема переходов: Обычный противник (`NormalEnemyAI`)

| **Текущее состояние** | **Условие перехода**                           | **Следующее состояние** |
| --------------------- | ---------------------------------------------- | ----------------------- |
| **Idle**              | Игрок обнаружен (`SeePlayer() == true`)        | **Chase**               |
| **Idle**              | Завершилось время ожидания (`stateTimer <= 0`) | **Patrol**              |
| **Patrol**            | Игрок обнаружен (`SeePlayer() == true`)        | **Chase**               |
| **Patrol**            | Достигнута точка патрулирования                | **Idle**                |
| **Chase**             | Дистанция до игрока $\le$ `attackRange`        | **Attack**              |
| **Chase**             | Игрок потерян из виду (`SeePlayer() == false`) | **Search**              |
| **Attack**            | Дистанция до игрока > `attackRange`            | **Chase**               |
| **Attack**            | Персонаж игрока уничтожен / отсутствует        | **Patrol**              |
| **Search**            | Игрок вновь обнаружен (`SeePlayer() == true`)  | **Chase**               |
| **Search**            | Время поиска истекло (`stateTimer <= 0`)       | **Patrol**              |

### Обычный противник (`NormalEnemyAI`)

- **Восприятие:** Направленное зрение под углом 180° с дальностью `viewDistance`. Для проверки препятствий используется `Physics2D.Raycast`, объединяющий слои `obstacleLayer` и `playerLayer`.
- **Патрулирование:** Перемещение между зафиксированными точками `patrolPoints`. По прибытии в точку NPC делает паузу в состоянии `Idle`.
- **Поиск:** При утере контакта NPC перемещается к `lastKnownPos` и начинает вращаться вокруг своей оси, имитируя осмотр местности в течение `searchDuration` секунд.
### Телепортирующийся противник (`TeleportEnemyAI`)

- **Восприятие:** Круговое сканирование на 360° с радиусом `scanRadius` и заданным интервалом проверки `scanInterval`
- **Способность телепортации:** При преследовании цели на расстоянии более 2.5 м противник выполняет телепортацию в направлении игрока на расстояние до `maxTpDistance`
- **Защита от застревания в стенах:** Перемещение производится с предварительной геометрической проверкой через `Raycast`. Если на пути телепортации находится объект слоя `obstacleLayer`, точка назначения смещается перед препятствием (`hit.point - dirToPlayer * 0.5f`)
